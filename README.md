### 👨‍💻 About me

I'm a frontend developer with about five years of experience, working mainly with **React** and **TypeScript**. I like interfaces that stay fast and predictable as they grow: strict types, clear architecture (Feature-Sliced Design, monorepos), accessible components and real tests.

Lately I've been going further down the stack, building the APIs behind my frontends with **NestJS + Prisma + PostgreSQL** and **ASP.NET Core**.

- 🔭 **Now:** *Vaka*, an audit-ready digital cleaning log for production plants (ASP.NET Core 10)
- 🧩 **Building:** the *TUDOS* stack: a Next.js 16 task board, its NestJS API and a headless DataGrid library
- 🌱 **Learning:** backend architecture, auth & security, caching, and testing at the API level
- 📫 **Reach me:** [haktan.albayrak01@gmail.com](mailto:haktan.albayrak01@gmail.com)
